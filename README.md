# 🧩 Atividades-DOM2

Exercícios práticos de **manipulação de arrays com DOM** em JavaScript, focados nos quatro métodos essenciais: `filter()`, `find()`, `reduce()` e `forEach()`.

---

## 🎯 Objetivo

Praticar a leitura de dados via `input`, a transformação de strings em arrays e a exibição dinâmica de resultados na página — tudo isso usando os principais métodos de array do JavaScript.

---

## 📚 Conteúdo abordado

| Método | O que faz | Exemplos no projeto |
|--------|-----------|---------------------|
| `filter()` | Filtra elementos que passam em um teste | Idades ≥ 18, números pares, múltiplos de 3 |
| `find()` | Retorna o **primeiro** elemento que passa no teste | Primeira "maçã", primeiro número negativo |
| `reduce()` | Reduz o array a um único valor | Soma, média, produto, total de compras |
| `forEach()` | Executa uma ação para cada item | Saudações, dobro dos números, aprovado/reprovado |

---

## 🛠️ Tecnologias

- **HTML5** — estrutura e inputs
- **CSS3** — design moderno com glassmorphism, animações e tema escuro
- **JavaScript (Vanilla)** — lógica dos métodos de array e manipulação do DOM
